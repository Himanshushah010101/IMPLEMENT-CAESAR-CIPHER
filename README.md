🚀 Project: Caesar Cipher Implementation (Cryptography Tool)

I have developed a simple yet effective Caesar Cipher encryption and decryption tool using Python as part of my cybersecurity learning journey.

🔐 About the Project:
This project demonstrates one of the oldest cryptographic techniques where each character in a text is shifted by a fixed number (key) to convert plaintext into ciphertext and vice versa.

⚙️ Key Features:

Encrypt text using Caesar Cipher algorithm
Decrypt encrypted messages using the same shift key
Supports both uppercase and lowercase letters
Preserves numbers, spaces, and special characters
Simple command-line interface for user interaction

💡 What I Learned:

Basics of Cryptography and Encryption techniques
String manipulation and ASCII operations in Python
Importance of secure communication concepts
Foundational understanding of classical ciphers in cybersecurity
